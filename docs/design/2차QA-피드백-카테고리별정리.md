## 🟥 백엔드 — 내 담당(🟢) 우선순위

### 매칭/대기방 (심각)
1. **랜덤매칭 "이미 매칭 대기 중" 뜨며 큐가 영원히 안 잡힘, 대기시간 안 늘어남** 🟢 ← 최우선
2. **랜덤매칭 한 명 퇴장 시 방 폭파+남은 사람 자동 큐** 로 구현했는데 → 퇴장해도 방/인원 그대로 🟢
3. **없는 방코드 입력해도** 카메라 권한·유령 대기방 입장까지 됨 → **아예 입장 차단**(정원 초과 방도 동일) 🟢
4. **초대방 방장 나가면 위임 안 되게 했는데** → 재입장 시 **서로 방장**으로 뜸 + 방장 역할 소실(둘 다 게임시작 버튼 없음) 🟢
5. 리듬/에어하키 **친구 대결 코드가 같아도 같은 방 입장 안 됨** 🟢

### 랭킹 (내 담당)
6. **0점도 랭킹에 뜸 → 0 이하 제외** 🟢 *(방금 논의, 코드 한 줄)*
7. **탈퇴 계정이 랭킹에 `withdrawn-00`으로 남음 → 랭킹에서 제외** 🟢
8. 랭킹/게임 **카테고리 이름 오류**("눈 깜빡이기"가 "깜빡임 참기"로 표시) — 표시명 (BE enum↔FE 매핑, 아래 FE와 함께)

### 소모임
9. **소모임 검색 6글자 제한 + 비공개방도 조회 가능**하게 수정 🟢(+FE 입력제한)

### 게임 결과/전적
10. **마이페이지 최근 경기 "상세 조회" 반영 안 됨** 🟢(gameResult 상세) +FE

### auth·user (⚪ 다른 분)
11. **이메일 형식 검증 없음** — `321@321.321`로도 회원가입됨 ⚪(+FE 폼검증)
12. **토큰 만료 안 됨** — 어제 로그인했는데 아직 로그인 상태 ⚪(만료 정책 확인)

## 🟦 프론트엔드 (UI·상태·표시)

13. **로그인 창 값이 나갔다 와도 남아있음**(폼 상태 초기화 안 됨)
14. **웹캠 설정 "나중에 하기" 눌러도 설정 "완료"로 처리됨**(취소여야 함)
15. **랭킹 게임 카테고리 이름** 실제 게임명으로 (8과 연결 — FE 표시명 매핑)

## 🖥 결과 화면 (여러 건 — 별도 묶음, 대부분 FE)

20. **에어하키 무승부 화면** 신규 구현 필요
21. **깜빡이기 신기록 못했을 때 "일반 화면"** 구현 필요 *(백엔드 isNewRecord는 5단계에서 됨 — FE 조건부 표시)*
