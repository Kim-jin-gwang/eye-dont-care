# 게임 상세 조회

URL: /api/v1/games/{gameId}
method: GET
도메인: Game
진행상황: 완료

# **게임 상세 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 완료 |
| Method | `GET` |
| URL | `/api/v1/games/{gameId}` |
| 구분 | 필수 |
| 인증 | 불필요 |
| 역할 | 공통 |
| 사용할 페이지 | 게임 상세 |
| 담당자 | 김진광 |
| 도메인 | Game |
| 설명 | 게임 한 행의 상세. 플레이 모드와 난이도를 확인한다. |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| - | - | - | 인증/본문 없음 |

### **Role Requirement**

---

**권한:** 누구나 조회할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| gameId | Long | NOT NULL | 게임 ID(Path) |

### **요청 예시**

---

```json
GET /api/v1/games/7
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| gameId | Long | NOT NULL | 게임 ID |
| gameName | String(enum) | NOT NULL | EYEFIGHT / BLINK / DRAWING / RHYTHM / HOCKEY |
| playMode | String(enum) | NOT NULL | SOLO / INVITE / RANDOM / AI |
| difficulty | int | NULL | 난이도. 1(EASY) / 2(NORMAL) / 3(HARD). 눈싸움 AI 대결만 값을 가짐 |

`rule`, `controlGuide`, `minPlayers`, `maxPlayers`는 반환하지 않습니다. 게임 규칙·조작 방법·인원 등 표시용 데이터는 프론트엔드가 관리합니다.

### **응답 예시**

---

### **200 OK** — 난이도가 있는 경우

눈싸움 AI 대결

```json
HTTP/1.1 200
Content-Type: application/json

{
  "code": "GAME_FOUND",
  "message": "게임 상세를 조회했습니다.",
  "data": {
    "gameId": 7,
    "gameName": "EYEFIGHT",
    "playMode": "AI",
    "difficulty": 1
  }
}
```

### **200 OK** — 난이도가 없는 경우

```json
HTTP/1.1 200
Content-Type: application/json

{
  "code": "GAME_FOUND",
  "message": "게임 상세를 조회했습니다.",
  "data": {
    "gameId": 2,
    "gameName": "HOCKEY",
    "playMode": "RANDOM",
    "difficulty": null
  }
}
```

### **400 BAD REQUEST**

`gameId`가 숫자가 아닌 경우

```json
HTTP/1.1 400
Content-Type: application/json

{
  "code": "COMMON-004",
  "message": "요청 값의 타입이 올바르지 않습니다.",
  "data": null
}
```

### **404 NOT FOUND**

```json
HTTP/1.1 404
Content-Type: application/json

{
  "code": "GAME-001",
  "message": "게임을 찾을 수 없습니다.",
  "data": null
}
```

### **500 INTERNAL SERVER ERROR**

```json
HTTP/1.1 500
Content-Type: application/json

{
  "code": "COMMON-500",
  "message": "서버 내부 오류가 발생했습니다.",
  "data": null
}
```

### **난이도별 gameId (현재 시드 기준)**

---

눈싸움 AI 대결만 난이도가 나뉩니다.

| gameId | gameName | playMode | difficulty | 제한 시간 |
| --- | --- | --- | --- | --- |
| 7 | EYEFIGHT | AI | 1 (EASY) | 15초 |
| 8 | EYEFIGHT | AI | 2 (NORMAL) | 30초 |
| 9 | EYEFIGHT | AI | 3 (HARD) | 1분 |

나머지 13개 행은 `difficulty`가 `null`입니다.

제한 시간은 게임 기획 값이며 서버가 반환하지 않습니다. 프론트엔드가 난이도에 매핑해 표시합니다.
