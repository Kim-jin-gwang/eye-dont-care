## ⚠️ 팀원 필수 세팅 (그림 인식용 — 안 하면 그림 제출이 실패함)

그림 인식(Vision API)은 **비밀 키**가 필요한데, 키가 담긴 `.env`는 git에 안 올라갑니다(보안).
그래서 **각자 로컬에 아래 세팅**을 해야 합니다.

```bash
# 1) 최신 dev
git checkout dev && git pull

# 2) 로컬 .env 에 Vision API 항목 추가 (.env 없으면 .env.example 복사)
#    VISION_API_KEY=<데이터/백엔드 담당이 안전 채널로 공유한 값>
#    VISION_API_BASE_URI=https://api.openai.com/v1/chat/completions
#    VISION_API_MODEL=gpt-4o

# 3) 백엔드 재빌드 (옛 이미지엔 인식 엔드포인트가 없어 404가 남)
docker compose -f compose.dev.yml up -d --build backend
```

| 증상 | 원인 | 해결 |
|---|---|---|
| "요청한 리소스를 찾을 수 없습니다"(404) | 백엔드가 옛 빌드(엔드포인트 없음) | 위 1·3번(최신화 + `--build`) |
| "그림 인식 서비스가 설정되지 않았습니다"(503) | `.env`에 Vision API 키 없음 | 위 2번(각자 키 설정) |

> **VISION_API_KEY 값은 팀 채팅 DM 등 안전한 채널로 공유** 받으세요. git·명세서에 올리지 마세요.

## 테스트 팁
- 코드 수정 후에는 **컨테이너 재빌드/재시작**해야 반영됩니다(Windows Docker는 HMR이 파일 변경을 못 잡음).
- 캘리브레이션·카메라 기능은 **웹캠 + 소리** 켜고 테스트.

## 남은 것(후속)
- **release(배포) 시**: `compose.prod.yml`에도 Vision API 전달을 추가해야 함(현재 dev에만 있음) + 서버에 키 1회 설정. → 배포하면 팀원 개별 세팅은 불필요해짐.
- 멀티 이탈 "상대 자동 승리·전적 기록"까지는 후속 과제(현재는 상대에게 이탈 통지까지).
- 강퇴(kick)는 백엔드에 있으나 프론트 연동 미구현.
