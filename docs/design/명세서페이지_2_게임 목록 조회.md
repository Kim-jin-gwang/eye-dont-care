# 게임 목록 조회

URL: /api/v1/games
method: GET
도메인: Game
진행상황: 완료

# **게임 목록 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 완료 |
| Method | `GET` |
| URL | `/api/v1/games` |
| 구분 | 필수 |
| 인증 | 불필요 |
| 역할 | 공통 |
| 사용할 페이지 | 게임 목록 |
| 담당자 | 김진광 |
| 도메인 | Game |
| 설명 | 게임 카탈로그. 한 행은 (게임 × 플레이 모드 × 난이도) 조합을 의미한다. |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| - | - | - | 인증/본문 없음 |

### **Role Requirement**

---

**권한:** 누구나 조회할 수 있습니다.

### **Request Elements**

---

요청 파라미터 없음

### **요청 예시**

---

```json
GET /api/v1/games
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| games | Array | NOT NULL | 게임 목록 |

**games 배열 요소**

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| gameId | Long | NOT NULL | 게임 ID |
| gameName | String(enum) | NOT NULL | EYEFIGHT / BLINK / DRAWING / RHYTHM / HOCKEY |
| playMode | String(enum) | NOT NULL | SOLO / INVITE / RANDOM / AI |

`summary`, `thumbnailUrl`은 반환하지 않습니다. 한글 게임명·이미지·카테고리 등 표시용 데이터는 프론트엔드가 `gameName` ENUM 기준으로 매핑합니다.

### **프론트엔드 주의사항**

---

**같은 게임이 모드별로 여러 행 반환됩니다. 현재 16행입니다.**

`gameName`으로 묶어서 모드 선택 버튼을 구성해야 합니다.

| 게임 | 행 수 | 모드 |
| --- | --- | --- |
| HOCKEY | 3 | INVITE / RANDOM / AI |
| EYEFIGHT | 6 | SOLO / INVITE / RANDOM / AI(난이도 1·2·3) |
| DRAWING | 1 | AI |
| RHYTHM | 3 | SOLO / INVITE / RANDOM |
| BLINK | 3 | SOLO / INVITE / RANDOM |

`gameId` 7·8·9는 눈싸움 AI 대결의 난이도 1·2·3입니다. **목록 응답에는 난이도가 없어 구분되지 않습니다.**
AI 난이도를 선택하는 화면이 필요하면 상세 조회를 호출해야 합니다.

서버가 프론트엔드에 없는 `gameName` 값을 반환할 수 있으므로, 알 수 없는 게임명일 때의 기본 처리를 두는 것을 권장합니다.
