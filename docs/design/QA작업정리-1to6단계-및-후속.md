## ✅ 오늘 완료 (전부 dev 머지)

### 1단계 — 캘리브레이션
- 각 단계(눈 뜨기·감기·시선) 성공/완료/거절 **효과음** (Web Audio, 에셋 없음)
- **눈 상태 게이트**: 눈 뜨기 단계에 감았거나 감기 단계에 떴으면 다음으로 안 넘어감 + 안내

### 2단계 — 눈으로 그리기
- **Vision API 인식 연동**: 컨테이너에 `VISION_API_KEY` 미전달이 원인 → compose 전달 + 실패 원인 로깅
- **제출 시 스페이스 유지**: 제출이 일시정지 상태를 건드리지 않음(채점 중 입력은 phase로 차단)
- **게임 이탈 처리**: 카메라 종료·새로고침 시 게임 종료(멀티=세션 close 몰수/솔로=종료),
  프레임 정지 watchdog, 새로고침 시 재시작 방지

### 3단계 — 소모임 삭제
- 상세 화면에 **방장용 "소모임 삭제"** 버튼 + 확인창 (백엔드 API는 기존 존재, 연동만 없던 상태)
- 규칙: 방장=삭제 / 멤버=나가기

### 4단계 — 랜덤 매칭
- 대결 중 **상대 이탈 시 게임 종료**(남은 사람 결과 화면으로)

### 5단계 — 눈 깜빡이기 점수
- 랭킹 점수 = **깜빡인 횟수 그대로**(기존 ×10 → 실제 횟수). 화면 표시는 영향 없음

### 6단계 — gaze(시선)
- **좌우 이중 반전 제거**: 소스·screenGaze 두 곳에서 x를 각각 뒤집던 버그 정리(한 번만)
- **캘리브 정확도 개선**: 각 점에서 1프레임 → ~0.5초 다중 프레임 평균(클릭 수·UX 동일)
- **품질 검증**: 훈련오차(과적합) 대신 raw↔타깃 상관관계로 "실제 응시" 판정 → 낮으면 재보정 권유

### 추가(후속 항목 중 처리분)
- **배포용 Vision API 전달**: `compose.prod.yml`에도 Vision API 환경변수 추가(선택값)
- **Vision API 요청 로그 debug 강등**
- **소모임 멤버 강퇴(방장)** 프론트 연동

## 🔜 후속으로 해야 할 것

### A. 멀티 이탈 — 전적·랭킹 기록 (미완)
- 지금: 상대 이탈 시 **몰수승 결과 화면 표시 + 정상종료 구분(GAME_OVER)** 까지만.
- 남음: 몰수승/패를 **백엔드 전적·랭킹에 실제 기록**. 나간 사람 클라가 떠나 양측 기록이 어렵고,
  랭킹 데이터에 쓰는 작업이라 **2인 라이브 검증 후** 진행이 안전.
- 더 견고하게: **서버(게임 세션 WS)가 정상 종료(GAME_OVER)와 중도 이탈을 구분해 브로드캐스트** →
  현재는 클라 로직으로 처리 중.
- ⚠️ **머지분 2인 검증 필요**: 4·6단계·몰수승은 테스트 상대가 없어 라이브 미검증. 2인으로
  (1)상대 이탈 시 몰수승 (2)정상 대결이 정상 종료되는지 확인 권장.

### B. gaze 위치 정확도 (팀 논의)
- 현재: 다중표본 평균으로 개선했지만 **9점 캘리브 + 웹캠 한계**로 위치 정확도는 여전히 부족.
- 옵션: **촘촘한 캘리브(9→25점) + 응시(dwell) 자동 진행**(클릭 안 늘려 UX 유지), 스무더 게임별 튜닝
  (그림=안정 / 에어하키=반응), 또는 웹캠 한계 감안해 **큰 타깃·응시 선택 중심 설계**.
- 스무딩은 "떨림/지연(느낌)"용이라 "위치가 틀림"은 캘리브·모델 문제 — 별개.

### C. 기타
- 강퇴 외 소모임 상세의 게시글/일정 등은 백엔드에도 없음(신규 스코프, 팀 결정 필요)

## 👥 팀원 / 배포 액션

### 팀원 (로컬) — 그림 인식 쓰려면 필수
```bash
git checkout dev && git pull
# 로컬 .env 에 추가 (키는 안전 채널로 공유받기)
#   VISION_API_KEY=<공유받은 값>
#   VISION_API_BASE_URI=https://api.openai.com/v1/chat/completions
#   VISION_API_MODEL=gpt-4o
docker compose -f compose.dev.yml up -d --build backend
```
- 404("리소스 없음") = 최신화·재빌드 안 됨 / 503("설정 안 됨") = `.env`에 키 없음
- 코드 수정 반영은 **컨테이너 재빌드/재시작** 필요(Windows는 HMR 미동작)

### 배포
- 배포 환경 시크릿에 **`VISION_API_KEY` 1회 등록** (compose.prod.yml은 전달만 함)
