# 게임 결과 제출

URL: /api/v1/game-results
method: POST
도메인: GameResult
진행상황: 완료

# **게임 결과 제출**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 완료 |
| Method | `POST` |
| URL | `/api/v1/game-results` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 공통(회원/게스트) |
| 사용할 페이지 | 게임 결과 |
| 담당자 | 김진광 |
| 도메인 | GameResult |
| 설명 | 게임 종료 후 프론트 계산 결과 제출. playId를 멱등키로 사용해 중복 제출을 차단한다. 나가기는 FORFEIT으로 제출한다. |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| X-Participant-Key | String | 필수 | 임시 인증 헤더. `USER:{userId}` 또는 `GUEST:{guestSessionId}` 형식. 인증 도메인 완성 시 `Authorization`으로 교체 |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 경기 참가자가 요청합니다. 요청자가 `participants`에 포함되어 있지 않으면 거부됩니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| playId | String(UUID) | NOT NULL | 클라 생성 멱등키. 재시도 시 동일 값 전송 |
| gameId | Long | NOT NULL | 게임 ID. (게임 × 플레이 모드 × 난이도) 조합을 식별 |
| startedAt | String(ISO 8601) | NOT NULL | 경기 시작 시각 |
| endedAt | String(ISO 8601) | NOT NULL | 경기 종료 시각 |
| participants | Array | NOT NULL | participantKey, participantType, slotNo, displayName, outcome, rank |
| gameResult | Object(JSONB) | NOT NULL | 게임별 상세. 서버는 검증하지 않고 그대로 저장 |

**participants 배열 요소**

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| participantKey | String(50) | NOT NULL | `USER:{userId}` / `GUEST:{guestSessionId}` / `AI:{식별자}` |
| participantType | String(enum) | NOT NULL | USER / GUEST / AI |
| slotNo | int | NOT NULL | 슬롯 번호. `gameResult.players[].slotNo`와 연결 |
| displayName | String(50) | NOT NULL | 표시 이름. 게스트 닉네임 보존용 |
| outcome | String(enum) | NOT NULL | WIN / LOSE / DRAW / FORFEIT / COMPLETED |
| rank | int | NOT NULL | 최종 순위. 1 이상, 참가자 수 이하 |

`playMode`는 받지 않습니다. `gameId`가 이미 플레이 모드를 식별하므로 중복 정보입니다.

`score`는 받지 않습니다. 점수는 `gameResult` 안에 있고 랭킹 집계 시 파싱해 사용합니다.

### **요청 예시**

---

```json
POST /api/v1/game-results
X-Participant-Key: USER:1
Content-Type: application/json

{
  "playId": "019abcde-1234-4abc-8def-0123456789ab",
  "gameId": 1,
  "startedAt": "2026-07-28T09:00:00Z",
  "endedAt": "2026-07-28T09:01:00Z",
  "participants": [
    {
      "participantKey": "USER:1",
      "participantType": "USER",
      "slotNo": 1,
      "displayName": "눈싸움장인",
      "outcome": "WIN",
      "rank": 1
    },
    {
      "participantKey": "USER:2",
      "participantType": "USER",
      "slotNo": 2,
      "displayName": "초롱이",
      "outcome": "LOSE",
      "rank": 2
    }
  ],
  "gameResult": {
    "durationMs": 60000,
    "players": [
      { "slotNo": 1, "goals": 5 },
      { "slotNo": 2, "goals": 3 }
    ]
  }
}
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| resultId | Long | NOT NULL | 저장된 경기 결과 ID |

### **응답 예시**

---

### **201 CREATED**

```json
HTTP/1.1 201
Content-Type: application/json

{
  "code": "RESULT_SUBMITTED",
  "message": "게임 결과가 저장되었습니다.",
  "data": {
    "resultId": 5001
  }
}
```

### **400 BAD REQUEST** — 필수값 누락·형식 오류

```json
HTTP/1.1 400
Content-Type: application/json

{
  "code": "COMMON-001",
  "message": "요청 값이 올바르지 않습니다.",
  "data": {
    "fieldErrors": [
      {
        "field": "startedAt",
        "reason": "경기 시작 시각은 필수입니다."
      }
    ]
  }
}
```

### **400 BAD REQUEST** — 참가자 정보 오류

`slotNo` 중복, `rank`가 참가자 수 초과, `participantKey` 형식 오류

```json
HTTP/1.1 400
Content-Type: application/json

{
  "code": "GAMERESULT-003",
  "message": "참가자 정보가 올바르지 않습니다.",
  "data": null
}
```

### **400 BAD REQUEST** — 요청자가 참가자가 아님

```json
HTTP/1.1 400
Content-Type: application/json

{
  "code": "GAMERESULT-004",
  "message": "경기 참가자만 결과를 제출할 수 있습니다.",
  "data": null
}
```

### **400 BAD REQUEST** — 경기 시각 오류

`endedAt`이 `startedAt`보다 빠른 경우

```json
HTTP/1.1 400
Content-Type: application/json

{
  "code": "GAMERESULT-005",
  "message": "경기 시작 시각과 종료 시각이 올바르지 않습니다.",
  "data": null
}
```

### **404 NOT FOUND**

```json
HTTP/1.1 404
Content-Type: application/json

{
  "code": "GAMERESULT-002",
  "message": "게임을 찾을 수 없습니다.",
  "data": null
}
```

### **409 CONFLICT**

같은 `playId`로 재요청한 경우

```json
HTTP/1.1 409
Content-Type: application/json

{
  "code": "GAMERESULT-001",
  "message": "이미 제출된 결과입니다.",
  "data": null
}
```

### **500 INTERNAL SERVER ERROR**

```json
HTTP/1.1 500
Content-Type: application/json

{
  "code": "COMMON-500",
  "message": "서버 내부 오류가 발생했습니다.",
  "data": null
}
```

### **특수 케이스**

---

**몰수 (나가기 버튼)**

`outcome`을 `FORFEIT`으로 보내고 `gameResult`에는 중단 시점까지의 값을 담습니다.
새로고침·탭 종료·네트워크 단절은 결과를 저장하지 않습니다.

```json
{
  "playId": "019abcde-9999-4abc-8def-0123456789ab",
  "gameId": 1,
  "startedAt": "2026-07-28T09:00:00Z",
  "endedAt": "2026-07-28T09:00:12Z",
  "participants": [
    {
      "participantKey": "USER:1",
      "participantType": "USER",
      "slotNo": 1,
      "displayName": "눈싸움장인",
      "outcome": "FORFEIT",
      "rank": 2
    },
    {
      "participantKey": "USER:2",
      "participantType": "USER",
      "slotNo": 2,
      "displayName": "초롱이",
      "outcome": "WIN",
      "rank": 1
    }
  ],
  "gameResult": {
    "durationMs": 12000,
    "players": [
      { "slotNo": 1, "goals": 1 },
      { "slotNo": 2, "goals": 2 }
    ]
  }
}
```

**게스트 참가자**

`user_id`는 저장되지 않고 `displayName`만 남습니다.

```json
{
  "participantKey": "GUEST:019abcde-5678-4abc-8def-0123456789ab",
  "participantType": "GUEST",
  "slotNo": 2,
  "displayName": "구경꾼",
  "outcome": "LOSE",
  "rank": 2
}
```

**AI 참가자**

```json
{
  "participantKey": "AI:EYEFIGHT-HARD",
  "participantType": "AI",
  "slotNo": 2,
  "displayName": "AI 하드",
  "outcome": "LOSE",
  "rank": 2
}
```
