# 소모임 멤버 강퇴

URL: /api/v1/groups/{groupId}/members/{userId}
method: DELETE
도메인: Group
진행상황: 시작 전

# **소모임 멤버 강퇴**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `DELETE` |
| URL | `/api/v1/groups/{groupId}/members/{userId}` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 방장(OWNER) |
| 사용할 페이지 | 커뮤니티/소모임 |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 방장이 특정 멤버를 강퇴. 자기 자신은 불가(나가기/삭제 사용) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 해당 소모임의 방장(OWNER)만. 대상은 본인 외 멤버.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| groupId | Long | NOT NULL | 소모임 ID(Path) |
| userId | Long | NOT NULL | 강퇴 대상 회원 ID(Path) |

### **요청 예시**

---

```json
DELETE /api/v1/groups/1/members/52
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

응답 data 없음 (`null`)

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{ "code": "GROUP_MEMBER_KICK_SUCCESS", "message": "멤버를 강퇴했습니다.", "data": null }
```

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

### **403 FORBIDDEN**

```json
{ "code": "GROUP-006", "message": "소모임 방장만 할 수 있습니다.", "data": null }
```

### **404 NOT FOUND**

```json
{ "code": "GROUP-001", "message": "소모임을 찾을 수 없습니다.", "data": null }
```

### **409 CONFLICT**

```json
{ "code": "GROUP-008", "message": "자기 자신은 강퇴할 수 없습니다.", "data": null }
```

> 대상이 해당 소모임 멤버가 아니면 `GROUP-010`(404, "강퇴할 멤버를 찾을 수 없습니다.").
