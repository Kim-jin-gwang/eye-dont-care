method: GET
도메인: User
진행상황: 시작 전

# **닉네임 중복 확인**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/users/nickname/check?nickname={nickname}` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 프로필 수정 |
| 담당자 |  |
| 도메인 | User |
| 설명 | 닉네임 수정 시 중복 확인 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원이 요청할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| nickname | String | NOT NULL | 확인할 닉네임(Query) |

### **요청 예시**

---

```json
GET /api/v1/users/nickname/check?nickname={nickname}
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| nickname | String | NOT NULL | 확인한 닉네임 |
| available | Boolean | NOT NULL | 사용 가능 여부 |

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "NICKNAME_CHECK_SUCCESS",
  "message": "닉네임 중복 확인이 완료되었습니다.",
  "data": {
    "nickname": "눈싸움장인",
    "available": true
  },
}
```

