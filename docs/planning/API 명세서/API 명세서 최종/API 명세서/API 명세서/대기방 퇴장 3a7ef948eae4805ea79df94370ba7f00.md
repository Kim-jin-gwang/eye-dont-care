# 대기방 퇴장

URL: /api/v1/waiting-rooms/{roomId}/leave
method: POST
도메인: WaitingRoom
진행상황: 시작 전

# **대기방 퇴장**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `POST` |
| URL | `/api/v1/waiting-rooms/{roomId}/leave` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 공통(회원/게스트) |
| 사용할 페이지 | 대기방 |
| 담당자 |  |
| 도메인 | WaitingRoom |
| 설명 | INVITE 대기방 퇴장. RANDOM 대기방 퇴장은 현재 임시 차단(WAITING-014) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 조건부 | 회원: JWT 액세스 토큰(Bearer) |
| X-Guest-Session-Id | String(UUID) | 조건부 | 게스트: 세션 ID |

### **Role Requirement**

---

**권한:** 대기방 참가자가 요청할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| roomId | String(UUID) | NOT NULL | 대기방 ID(Path) |

### **요청 예시**

---

```json
POST /api/v1/waiting-rooms/{roomId}/leave
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

응답 data 없음 (`null`)

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "WAITING_ROOM_LEAVE_SUCCESS",
  "message": "대기방 퇴장이 완료되었습니다.",
  "data": null,
}
```

### **401 UNAUTHORIZED**

```json
HTTP/1.1 401
Content-Type: application/json;

{
  "code": "SECURITY-001",
  "message": "인증이 필요합니다.",
  "data": null,
}
```

### **404 NOT FOUND**

```json
HTTP/1.1 404
Content-Type: application/json;

{
  "code": "WAITING-008",
  "message": "대기방을 찾을 수 없습니다.",
  "data": null,
}
```

### **409 CONFLICT**

```json
HTTP/1.1 409
Content-Type: application/json;

{
  "code": "WAITING-014",
  "message": "현재 상태에서는 요청한 상태로 변경할 수 없습니다.",
  "data": null,
}
```

> RANDOM 대기방 퇴장은 자동 재매칭 구현 전까지 `WAITING-014`로 임시 차단된다.
> 참가자를 찾을 수 없으면 `WAITING-009`(404).
