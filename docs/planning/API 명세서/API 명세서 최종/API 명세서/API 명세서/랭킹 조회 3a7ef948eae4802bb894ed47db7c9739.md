# 랭킹 조회

URL: /api/v1/rankings
method: GET
도메인: Ranking
진행상황: 시작 전

# **랭킹 조회 (홈 요약)**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/rankings` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 홈 |
| 담당자 |  |
| 도메인 | Ranking |
| 설명 | 게임별 주간 랭킹 TOP N + 내 순위 요약. 홈의 "이번 주 랭킹 TOP3"용 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원. 내 순위(`myRank`)는 요청자 기준. (게스트 제외)

### **Request Elements (Query)**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| limit | Integer | NULL | 게임별 상위 인원(기본 3) |

### **요청 예시**

---

```json
GET /api/v1/rankings?limit=3
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| period | String(enum) | 집계 기간. 현재 `weekly` (확장 대비) |
| weekStart | String(ISO date) | 이번 주 시작(KST 월요일). 주 전환 감지용 |
| games | Array | 게임별 랭킹 요약 |
| games[].gameName | String(enum) | 게임 |
| games[].rankType | String(enum) | `WIN_COUNT`(에어하키) / `BEST_SCORE`(그 외) |
| games[].unit | String(enum) | 표시 단위 `win` / `second` / `point` / `count` |
| games[].top | Array | 상위 {rank, userId, nickname, value} |
| games[].myRank | Object\|null | 내 순위 {rank, value}. 미기록 시 null |

> `value`는 각 게임 점수(눈싸움=초 정수·깜빡이=회·점수게임=점·에어하키=승수). 랭킹은 `game_result[slot].score`(에어하키는 `outcome=WIN` 카운트)를 읽고, 동점은 **먼저 달성한 순**(achievedAt asc)으로 매긴다.

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

> 게임별 전체 랭킹(페이지네이션)은 `GET /api/v1/rankings/{gameName}` 참조.
