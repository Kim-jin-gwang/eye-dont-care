# 소모임 목록·검색

URL: /api/v1/groups
method: GET
도메인: Group
진행상황: 시작 전

# **소모임 목록·검색**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/groups` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 커뮤니티/소모임 |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 공개(PUBLIC) 소모임 목록. 이름 키워드 검색·페이지네이션 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원만 조회할 수 있습니다.

### **Request Elements (Query)**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| keyword | String | NULL | 이름 부분검색어 |
| page | Integer | NULL | 1부터(기본 1) |
| size | Integer | NULL | 페이지 크기(기본 20) |

### **요청 예시**

---

```json
GET /api/v1/groups?keyword=눈&page=1&size=20
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| groups | Array | 소모임 카드 목록(필드는 "소모임 생성" 응답과 동일) |
| page / size | Integer | 현재 페이지·크기 |
| totalElements | Long | 전체 개수 |
| totalPages | Integer | 전체 페이지 수 |

> 목록 항목의 `isJoined`/`isOwner`는 요청자 기준으로 채워지고, **비가입 항목의 `joinCode`는 null**이다.

### **응답 예시**

---

```json
Content-Type: application/json;

{
  "code": "GROUP_LIST_FOUND",
  "message": "소모임 목록을 조회했습니다.",
  "data": {
    "groups": [
      {
        "groupId": 1,
        "name": "눈운동 모임",

        "members": 3,
        "capacity": 10,
        "visibility": "PUBLIC",

```

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

> PRIVATE 소모임은 목록·검색에 노출되지 않는다(코드 입장 전용).
