# [WS] 대기방 상태 수신

URL: /ws/waiting-rooms/{roomId}
method: S→C
도메인: WaitingRoom
진행상황: 시작 전

# **[WS] 대기방 실시간 연결·상태 수신**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| 통신 | WebSocket |
| 방향 | S→C (연결·인증은 C→S 첫 프레임) |
| Connection | `/ws/waiting-rooms/{roomId}` |
| 구분 | 필수 |
| 역할 | 공통(회원/게스트) |
| 사용할 페이지 | 대기방 |
| 도메인 | WaitingRoom |
| 설명 | 연결 직후 인증 프레임 1회 전송 → 인증 성공 시 전체 상태(ROOM_STATE) 수신, 이후 변경 시마다 전체 상태 재전송 |

### **연결 정보**

---

| 항목 | 값 |
| --- | --- |
| Endpoint | `/ws/waiting-rooms/{roomId}` (roomId = 대기방 UUID) |
| 프로토콜 | WebSocket (permitAll, 인증은 첫 프레임으로) |
| 서버→클라 프레임 | `{ "type": string, "data": object }` |
| 이벤트 종류 | `ROOM_STATE`, `GAME_START`, `ERROR` |

### **Role Requirement**

---

**권한:** 해당 대기방 참가자만 연결 가능. 참가자가 아니면 `WAITING-009`로 종료.

### **1) 연결 직후 — 인증 프레임 (C→S, 필수)**

---

연결 후 **첫 메시지로 인증 프레임을 반드시 전송**한다. 미전송 시 타임아웃(`WAITING-012`)으로 연결 종료.

- 회원

```json
{ "type": "AUTH", "accessToken": "{JWT 액세스 토큰}" }
```

- 게스트

```json
{ "type": "AUTH", "guestSessionId": "{게스트 세션 UUID}" }
```

> 인증 실패: 토큰 무효 `SECURITY-002`, 참가자 아님 `WAITING-009`, 알 수 없는 필드/형식 오류 `WAITING-011`, 이미 연결됨 `WAITING-010`, 인증 시간 초과 `WAITING-012`.

### **2) 대기방 전체 상태 (S→C) — `ROOM_STATE`**

---

인증 성공 직후 1회, 이후 참가/퇴장·준비·캘리브레이션·카운트다운·방 상태 변경 때마다 **전체 상태**를 재전송한다.

| 필드(data) | 타입 | 설명 |
| --- | --- | --- |
| roomId | String(UUID) | 대기방 ID |
| roomType | String(enum) | `INVITE` / `RANDOM` |
| gameName | String(enum) | 게임 종류 |
| roomCode | String(CHAR4) | 방 코드 |
| roomStatus | String(enum) | `WAITING` / `COUNTDOWN` / `IN_GAME` / `CLOSED` |
| countdownEndsAt | String(ISO-8601) | `COUNTDOWN`일 때만 값, 그 외 null |
| participants | Array | 아래 참가자 객체 배열(slotNo 오름차순) |
| createdAt | String(ISO-8601) | 방 생성 시각 |

참가자 객체:

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| participantKey | String | `USER:{id}` / `GUEST:{uuid}` |
| displayName | String | 표시 이름 |
| roomRole | String(enum) | `HOST` / `PLAYER` |
| slotNo | int | 자리 번호(1,2) |
| isReady | boolean | 준비 여부 |
| calibrationStatus | String(enum) | `PENDING` / `IN_PROGRESS` / `COMPLETED` |
| joinedAt | String(ISO-8601) | 입장 시각 |

```json
{
  "type": "ROOM_STATE",
  "data": {
    "roomId": "019abcde-1234-4abc-8def-0123456789ab",
    "roomType": "INVITE",
    "gameName": "EYEFIGHT",
    "roomCode": "A1B2",
    "roomStatus": "WAITING",
    "countdownEndsAt": null,
    "participants": [
      { "participantKey": "USER:1", "displayName": "방장", "roomRole": "HOST", "slotNo": 1, "isReady": false, "calibrationStatus": "PENDING", "joinedAt": "2026-07-31T10:00:00Z" },
      { "participantKey": "GUEST:019abcde-...", "displayName": "졸린너구리", "roomRole": "PLAYER", "slotNo": 2, "isReady": false, "calibrationStatus": "PENDING", "joinedAt": "2026-07-31T10:01:00Z" }
    ],
    "createdAt": "2026-07-31T10:00:00Z"
  }
}
```

### **3) 게임 시작 (S→C) — `GAME_START`**

---

카운트다운 종료로 게임이 시작되면 전송하고, 서버는 소켓을 정상 종료한다(이후 인게임 소켓으로 전환).

```json
{
  "type": "GAME_START",
  "data": {
    "roomId": "019abcde-1234-4abc-8def-0123456789ab",
    "gameName": "EYEFIGHT",
    "startedAt": "2026-07-31T10:05:00Z"
  }
}
```

### **4) 오류 (S→C) — `ERROR`**

---

명령 처리 실패 시 전송. 5xx·형식 오류는 전송 후 연결 종료, 그 외 비즈니스 오류는 연결 유지.

```json
{
  "type": "ERROR",
  "data": {
    "code": "WAITING-016",
    "message": "다른 참가자가 아직 준비되지 않았어요."
  }
}
```

> 관련: [WS] 준비 상태 변경, [WS] 게임 시작 요청, [WS] 인게임 실시간 소켓(별도).
> 이 문서는 waitingroom 담당 구현 기준으로 정리됨 — 상태머신 세부는 담당자 확인 권장.
