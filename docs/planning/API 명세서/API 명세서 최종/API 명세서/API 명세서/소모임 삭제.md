# 소모임 삭제

URL: /api/v1/groups/{groupId}
method: DELETE
도메인: Group
진행상황: 시작 전

# **소모임 삭제**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `DELETE` |
| URL | `/api/v1/groups/{groupId}` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 방장(OWNER) |
| 사용할 페이지 | 커뮤니티/소모임 |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 방장이 소모임 삭제. 멤버(group_members)는 함께 삭제(cascade) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 해당 소모임의 방장(OWNER)만.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| groupId | Long | NOT NULL | 소모임 ID(Path) |

### **요청 예시**

---

```json
DELETE /api/v1/groups/1
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

응답 data 없음 (`null`)

### **응답 예시**

---
