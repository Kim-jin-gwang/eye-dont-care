# **게스트 세션 발급**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `POST` |
| URL | `/api/v1/auth/guest` |
| 구분 | 필수 |
| 인증 | 불필요 |
| 역할 | 비회원 |
| 사용할 페이지 | 전역 |
| 담당자 |  |
| 도메인 | Auth |
| 설명 | 식별 필요 최초 시점(매칭/방)에 자동 호출, UUID+랜덤 닉네임 발급 |

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |

### **Role Requirement**

---

---

요청 파라미터 없음

### **요청 예시**

---

```json
POST /api/v1/auth/guest
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| guestSessionId | String(UUID) | NOT NULL | 게스트 세션 ID(Redis) |
| displayName | String | NOT NULL | 서버 생성 랜덤 닉네임 |
