# 소모임 나가기

URL: /api/v1/groups/{groupId}/leave
method: POST
도메인: Group
진행상황: 시작 전

# **소모임 나가기**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `POST` |
| URL | `/api/v1/groups/{groupId}/leave` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원(멤버) |
| 사용할 페이지 | 커뮤니티/소모임 |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 멤버 본인이 소모임 탈퇴. 방장은 나갈 수 없음(삭제해야 함) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 해당 소모임의 멤버(MEMBER)만. 방장(OWNER)은 나가기 불가.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| groupId | Long | NOT NULL | 소모임 ID(Path) |

### **요청 예시**

---

```json
POST /api/v1/groups/1/leave
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

응답 data 없음 (`null`)

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{ "code": "GROUP_LEAVE_SUCCESS", "message": "소모임에서 나갔습니다.", "data": null }
```

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

### **403 FORBIDDEN**

```json
{ "code": "GROUP-005", "message": "소모임 멤버가 아닙니다.", "data": null }
```

### **404 NOT FOUND**

```json
{ "code": "GROUP-001", "message": "소모임을 찾을 수 없습니다.", "data": null }
```

### **409 CONFLICT**

```json
{ "code": "GROUP-007", "message": "방장은 나갈 수 없습니다. 소모임을 삭제하세요.", "data": null }
```
