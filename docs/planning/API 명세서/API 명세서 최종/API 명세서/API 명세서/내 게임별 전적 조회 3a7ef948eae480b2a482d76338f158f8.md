# 내 게임별 전적 조회

URL: /api/v1/game-results/me/stats
method: GET
도메인: GameResult
진행상황: 시작 전

# **내 게임별 전적 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/game-results/me/stats` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 마이페이지 |
| 담당자 |  |
| 도메인 | GameResult |
| 설명 | 게임별 누적 기록(참가자 집계 파생) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원이 조회합니다.

### **Request Elements**

---

요청 파라미터 없음

### **요청 예시**

---

```json
GET /api/v1/game-results/me/stats
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| stats | Object | NOT NULL | 게임(gameName)별 누적 지표 맵. 게임마다 상이 |

### **응답 예시**

---
