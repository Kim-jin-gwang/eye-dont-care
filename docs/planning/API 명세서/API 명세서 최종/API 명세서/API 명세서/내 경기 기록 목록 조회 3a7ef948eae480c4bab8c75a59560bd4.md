# 내 경기 기록 목록 조회

URL: /api/v1/game-results/me
method: GET
도메인: GameResult
진행상황: 시작 전

# **내 경기 기록 목록 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/game-results/me?page={page}&size={size}` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 마이페이지/기록 |
| 담당자 |  |
| 도메인 | GameResult |
| 설명 | 본인 기록 최신순·페이지네이션 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원이 본인 기록만 조회합니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| page | int | NULL | 페이지 번호(기본 1) |
| size | int | NULL | 페이지 크기(기본 10) |

### **요청 예시**

---

```json
GET /api/v1/game-results/me?page={page}&size={size}
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| content | Array | NOT NULL | 기록 목록. 각 원소 {resultId, gameName, playMode, difficulty, myOutcome, myRank, playedAt} |
| page | int | NOT NULL | 현재 페이지 |
| size | int | NOT NULL | 페이지 크기 |
| totalElements | int | NOT NULL | 전체 개수 |

### **응답 예시**
