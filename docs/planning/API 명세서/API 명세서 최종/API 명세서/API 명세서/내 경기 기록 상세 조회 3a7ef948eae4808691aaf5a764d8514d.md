# 내 경기 기록 상세 조회

URL: /api/v1/game-results/{gameResultId}
method: GET
도메인: GameResult
진행상황: 시작 전

# **내 경기 기록 상세 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/game-results/{resultId}` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 기록 상세 |
| 담당자 |  |
| 도메인 | GameResult |
| 설명 | 경기 세부 결과(참가자별 + game_result) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 경기 참가 회원이 조회합니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| resultId | Long | NOT NULL | 경기 결과 ID(Path) |

### **요청 예시**

---

```json
GET /api/v1/game-results/{resultId}
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| resultId | Long | NOT NULL | 경기 결과 ID |
| gameName | String | NOT NULL | 게임 종류 |
| playMode | String | NOT NULL | 모드 |
| difficulty | int | NULL | 난이도 |
| startedAt | String(ISO-8601) | NOT NULL | 시작 시각 |
| endedAt | String(ISO-8601) | NOT NULL | 종료 시각 |
| participants | Array | NOT NULL | 각 원소 {slotNo, participantType, displayName, outcome, rank} |
| gameResult | Object(JSONB) | NOT NULL | 제출된 게임별 상세 JSONB를 그대로 반환 |
