method: DELETE
도메인: Matchmaking
진행상황: 시작 전

# **랜덤 매칭 취소**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `DELETE` |
| URL | `/api/v1/match/cancel` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 공통(회원/게스트) |
| 사용할 페이지 | 로비/매칭 |
| 담당자 |  |
| 도메인 | Matchmaking |
| 설명 | 대기 중 매칭 큐 이탈 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 조건부 | 회원: JWT 액세스 토큰(Bearer) |
| X-Guest-Session-Id | String(UUID) | 조건부 | 게스트: 신청 시 발급받은 세션 ID(필수) |

### **Role Requirement**

---

**권한:** 매칭 대기 중인 사용자가 요청합니다.

### **Request Elements**

---

요청 파라미터 없음

### **요청 예시**

---

```json
DELETE /api/v1/match/cancel
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| participantKey | String | NOT NULL | `USER:{userId}` 또는 `GUEST:{uuid}` |
| gameType | String(enum) | NOT NULL | 취소한 매칭의 게임 |
| matchStatus | String(enum) | NOT NULL | `CANCELLED` (응답 전용 값, 저장되지 않음) |
| queuedAt | String(ISO-8601) | NOT NULL | 삭제 직전 큐 등록 시각 |
