# **프로필 이미지 수정**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `PUT` |
| URL | `/api/v1/users/me/profile-image` |
| 구분 | 도전 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 마이페이지 |
| 담당자 |  |
| 도메인 | User |
| 설명 | 프로필 이미지 등록/수정(multipart) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 인증된 회원이 요청할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| image | File(multipart) | NOT NULL | 프로필 이미지 파일 |

### **요청 예시**

---

```json
PUT /api/v1/users/me/profile-image
Authorization: Bearer jwt_token_string
Content-Type: application/json
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| profileImgUrl | String | NOT NULL | 갱신된 이미지 URL |

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "PROFILE_IMAGE_UPDATED",
  "message": "프로필 이미지가 수정되었습니다.",
  "data": {
    "profileImgUrl": "https://.../p.png"
  },
}
```

### **400 BAD REQUEST**

```json
HTTP/1.1 400
Content-Type: application/json;

{
  "code": "INVALID_IMAGE",
  "message": "이미지 형식/크기가 올바르지 않습니다.",
  "data": null,
}
```

### **401 UNAUTHORIZED**

```json
HTTP/1.1 401
Content-Type: application/json;

{
  "code": "AUTH_INVALID_TOKEN",
  "message": "유효하지 않은 인증 토큰입니다.",
  "data": null,
}
```

### **500 INTERNAL SERVER ERROR**

