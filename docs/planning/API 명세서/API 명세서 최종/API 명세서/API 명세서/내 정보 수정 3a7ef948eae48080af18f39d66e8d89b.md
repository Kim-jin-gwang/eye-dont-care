# 내 정보 수정

URL: /api/v1/users/{userId}
method: PATCH
도메인: User
진행상황: 시작 전

# **내 정보 수정**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `PATCH` |
| URL | `/api/v1/users/{userId}` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 마이페이지 |
| 담당자 |  |
| 도메인 | User |
| 설명 | 닉네임·프로필 이미지 부분 수정. path의 userId가 JWT 본인과 일치해야 한다 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 인증된 회원이 본인 정보만 수정합니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| nickname | String | 선택 | 변경할 닉네임 |
| profileImageCode | String(enum) | 선택 | 변경할 프로필 이미지 코드(예: PROFILE_1) |

> 부분 수정(PATCH)이다. 보낸 필드만 반영하며, 둘 다 없으면 `USER-006`.

### **요청 예시**

---

```json
PATCH /api/v1/users/{userId}
Authorization: Bearer jwt_token_string
Content-Type: application/json

{
  "nickname": "눈싸움종결자",
  "profileImageCode": "PROFILE_2"
}
```

### **Response Elements**

---

내 정보 조회와 동일한 사용자 정보를 반환한다.

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| id | Long | NOT NULL | 유저 ID |
| email | String | NULL | 이메일(카카오 회원은 null) |
| nickname | String | NOT NULL | 닉네임 |
| profileImageCode | String(enum) | NOT NULL | 프로필 이미지 코드 |
| loginType | String(enum) | NOT NULL | `LOCAL` / `KAKAO` |
| createdAt | String(ISO-8601) | NOT NULL | 가입 일시 |

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "USER_UPDATE_SUCCESS",
  "message": "내 정보 수정이 완료되었습니다.",
  "data": {
    "id": 42,
    "email": "user@example.com",
    "nickname": "눈싸움종결자",
    "profileImageCode": "PROFILE_2",
    "loginType": "LOCAL",
    "createdAt": "2026-07-24T09:00:00Z"
  },
}
```

### **400 BAD REQUEST**

```json
HTTP/1.1 400
Content-Type: application/json;

{
  "code": "USER-003",
  "message": "닉네임 형식이 올바르지 않습니다.",
  "data": null,
}
```

> 그 밖의 400: `USER-005`(유효하지 않은 프로필 이미지), `USER-006`(수정할 정보가 없음).

### **401 UNAUTHORIZED**

```json
HTTP/1.1 401
Content-Type: application/json;

{
  "code": "SECURITY-001",
  "message": "인증이 필요합니다.",
  "data": null,
}
```

### **403 FORBIDDEN**

```json
HTTP/1.1 403
Content-Type: application/json;

{
  "code": "USER-002",
  "message": "해당 사용자 정보에 접근할 수 없습니다.",
  "data": null,
}
```

### **409 CONFLICT**

```json
HTTP/1.1 409
Content-Type: application/json;

{
  "code": "USER-004",
  "message": "이미 사용 중인 닉네임입니다.",
  "data": null,
}
```
