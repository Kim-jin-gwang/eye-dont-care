### **Role Requirement**

---

**권한:** 대기방 참가자가 본인 상태만 변경합니다.

### **1) 준비 상태 전송 — `READY_STATUS` (C→S)**

---

- **설명**: `isReady` true/false 전환. INVITE는 반영 후 브로드캐스트. RANDOM은 양쪽 READY 시 카운트다운 자동 시작.

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| type | String | NOT NULL | `READY_STATUS` |
| isReady | boolean | NOT NULL | 준비 여부 |

```json
{
  "type": "READY_STATUS",
  "isReady": true
}
```

### **2) 캘리브레이션 상태 전송 — `CALIBRATION_STATUS` (C→S)**

---

- **설명**: 시선 보정 진행 상태 전송. 반영되면 전체 `ROOM_STATE` 재전송.

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| type | String | NOT NULL | `CALIBRATION_STATUS` |
| calibrationStatus | String(enum) | NOT NULL | `PENDING` / `IN_PROGRESS` / `COMPLETED` |

```json
{
  "type": "CALIBRATION_STATUS",
  "calibrationStatus": "COMPLETED"
}
```

### **응답 (S→C)**

---

- 성공: 전체 `ROOM_STATE` 브로드캐스트(별도 문서 [WS] 대기방 상태 수신 참조)
- 실패: `ERROR` 프레임 `{ "type": "ERROR", "data": { "code", "message" } }`
  - 잘못된 상태 전이 `WAITING-014`, 캘리브레이션 선행 필요 `WAITING-013`, 형식 오류 `WAITING-011`

> 필드명은 `isReady`(과거 초안 `is_ready`/`READY_UPDATE` 아님), 타입 값도 `READY_STATUS`로 확정.
