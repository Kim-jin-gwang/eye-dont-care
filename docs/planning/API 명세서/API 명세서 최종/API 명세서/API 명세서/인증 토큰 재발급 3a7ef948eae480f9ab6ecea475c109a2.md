# 인증 토큰 재발급

URL: /api/v1/auth/reissue
method: POST
도메인: Auth
진행상황: 시작 전

# **인증 토큰 재발급**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `POST` |
| URL | `/api/v1/auth/reissue` |
| 구분 | 필수 |
| 인증 | 불필요 |
| 역할 | 공통 |
| 사용할 페이지 | 전역 |
| 담당자 |  |
| 도메인 | Auth |
| 설명 | Refresh Token으로 토큰 쌍 재발급 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 유효한 Refresh Token 보유자가 요청할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| refreshToken | String | NOT NULL | 리프레시 토큰 |

### **요청 예시**

---

```json
POST /api/v1/auth/reissue
Content-Type: application/json

{
  "refreshToken": "eyJ..."
}
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| accessToken | String | NOT NULL | 새 액세스 토큰 |
| refreshToken | String | NOT NULL | 새 리프레시 토큰(회전) |

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "AUTH_REISSUE_SUCCESS",
  "message": "토큰 재발급이 완료되었습니다.",
  "data": {
    "accessToken": "eyJ...",
    "refreshToken": "eyJ..."
  },
}
```

### **401 UNAUTHORIZED**

```json
HTTP/1.1 401
Content-Type: application/json;

{
  "code": "AUTH-004",
  "message": "유효하지 않은 리프레시 토큰입니다.",
  "data": null,
}
```

### **500 INTERNAL SERVER ERROR**

```json
HTTP/1.1 500
Content-Type: application/json;

{
  "code": "UNEXPECTED_SERVER_ERROR",
  "message": "예상하지 못한 서버 오류가 발생했습니다.",
  "data": null,
}
```
