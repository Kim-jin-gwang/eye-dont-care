# 소셜 로그인

URL: /api/v1/auth/login/kakao
method: POST
도메인: Auth
진행상황: 시작 전

# **소셜 로그인 (카카오)**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `POST` |
| URL | `/api/v1/auth/login/kakao` |
| 구분 | 필수 |
| 인증 | 불필요 |
| 역할 | 비회원 |
| 사용할 페이지 | 로그인 페이지 |
| 담당자 |  |
| 도메인 | Auth |
| 설명 | 카카오 인가 코드로 로그인·자동가입. 현재 카카오만 구현(provider 경로 파라미터 없음) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 비회원(누구나) 요청할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| authorizationCode | String | NOT NULL | 카카오가 발급한 인가 코드 |

### **요청 예시**

---

```json
POST /api/v1/auth/login/kakao
Content-Type: application/json

{
  "authorizationCode": "kakao_authorization_code_here"
}
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| accessToken | String | NOT NULL | 액세스 토큰 |
| refreshToken | String | NOT NULL | 리프레시 토큰 |

> 현재 응답에 `tokenType`·`isNewUser`는 포함되지 않는다(미구현).

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "AUTH_KAKAO_LOGIN_SUCCESS",
  "message": "카카오 로그인이 완료되었습니다.",
  "data": {
    "accessToken": "eyJ...",
    "refreshToken": "eyJ..."
  },
}
```

### **400 BAD REQUEST**

```json
HTTP/1.1 400
Content-Type: application/json;

{
  "code": "COMMON-001",
  "message": "요청 값이 올바르지 않습니다.",
  "data": {
    "fieldErrors": [
      { "field": "authorizationCode", "reason": "인가 코드는 필수입니다." }
    ]
  },
}
```

### **401 UNAUTHORIZED**

```json
HTTP/1.1 401
Content-Type: application/json;

{
  "code": "AUTH-006",
  "message": "카카오 인증에 실패했습니다.",
  "data": null,
}
```

### **409 CONFLICT**

```json

{
  "code": "AUTH-008",
  "message": "소셜 계정 처리 중 충돌이 발생했습니다.",
  "data": null,
}
```

```json
  "message": "카카오 인증 서버와 통신할 수 없습니다.",

```
