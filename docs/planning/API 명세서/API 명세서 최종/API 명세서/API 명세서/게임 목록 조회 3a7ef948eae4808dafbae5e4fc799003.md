| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/games` |
| 구분 | 필수 |
| 인증 | 불필요 |
| 역할 | 공통 |
| 사용할 페이지 | 게임 목록 |
| 담당자 |  |
| 도메인 | Game |
| 설명 | 게임 카탈로그(대표 이미지·지원 모드) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| - | - | - | 인증/본문 없음 |

### **Role Requirement**

---

**권한:** 누구나 조회할 수 있습니다.

### **Request Elements**

---

요청 파라미터 없음

### **요청 예시**

---

```json
GET /api/v1/games
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| games | Array | NOT NULL | 게임 목록. 각 원소는 (게임 × 모드) 조합 1행이며 프론트가 `gameName`으로 그룹핑한다 |
| games[].gameId | Long | NOT NULL | 게임 ID |
| games[].gameName | String(enum) | NOT NULL | `EYEFIGHT`/`BLINK`/`DRAWING`/`RHYTHM`/`HOCKEY` |
| games[].playMode | String(enum) | NOT NULL | `SOLO`/`INVITE`/`RANDOM`/`AI` |

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "GAME_LIST_FOUND",
  "message": "게임 목록을 조회했습니다.",
  "data": {
    "games": [
      { "gameId": 1, "gameName": "EYEFIGHT", "playMode": "SOLO" },
      { "gameId": 2, "gameName": "EYEFIGHT", "playMode": "INVITE" },
      { "gameId": 3, "gameName": "EYEFIGHT", "playMode": "RANDOM" }
    ]
  },
}
```

> `summary`·`thumbnailUrl`은 현재 응답에 포함되지 않는다(미구현). 모드는 행마다 하나씩 내려가며 배열로 묶이지 않는다.
