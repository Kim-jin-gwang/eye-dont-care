# 내 정보 조회

URL: /api/v1/users/{userId}
method: GET
도메인: User
진행상황: 시작 전

# **내 정보 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/users/{userId}` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 마이페이지 |
| 담당자 |  |
| 도메인 | User |
| 설명 | 본인 프로필 조회. path의 userId가 JWT 사용자 본인과 일치해야 한다 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원이 본인 정보만 조회합니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| userId | Long | NOT NULL | 조회 대상 사용자 ID(Path). 본인만 허용 |

### **요청 예시**

---

```json
GET /api/v1/users/{userId}
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| id | Long | NOT NULL | 유저 ID |
| email | String | NULL | 이메일(카카오 회원은 null) |
| nickname | String | NOT NULL | 닉네임 |
| profileImageCode | String(enum) | NOT NULL | 프로필 이미지 코드(예: PROFILE_1) |
| loginType | String(enum) | NOT NULL | `LOCAL` / `KAKAO` |
| createdAt | String(ISO-8601) | NOT NULL | 가입 일시 |
