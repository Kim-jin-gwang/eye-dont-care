# **[WS] 게임 시작 요청**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| 통신 | WebSocket |
| 방향 | C→S |
| Connection | `/ws/waiting-rooms/{roomId}` |
| 구분 | 필수 |
| 역할 | 방장(INVITE) |
| 사용할 페이지 | 대기방 |
| 도메인 | WaitingRoom |
| 설명 | INVITE 방장만. 모든 PLAYER `isReady=true`일 때 유효. 성공 시 카운트다운→게임 시작 |

### **연결 정보**

---

| 항목 | 값 |
| --- | --- |
| Endpoint | `/ws/waiting-rooms/{roomId}` |
| 프로토콜 | WebSocket (연결 후 AUTH 프레임 선행) |
| 클라→서버 프레임 | `{ "type": "START_GAME" }` |

### **Role Requirement**

---

**권한:** INVITE 대기방 방장(HOST)만 요청합니다.

### **게임 시작 요청 전송 — `START_GAME` (C→S)**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| type | String | NOT NULL | `START_GAME` (추가 필드 없음) |

```json
{
  "type": "START_GAME"
}
```

### **응답 (S→C)**

---

- 성공: 방 상태 `COUNTDOWN` 전이 → 전체 `ROOM_STATE`(countdownEndsAt 포함) 브로드캐스트 → 카운트다운 종료 시 `GAME_START` 전송 후 소켓 정상 종료
- 실패: `ERROR` 프레임
  - 방장 아님 `WAITING-015`, 참가자 미준비 `WAITING-016`, 잘못된 상태 `WAITING-014`, 형식 오류 `WAITING-011`, 내부 오류 `WAITING-003`

```json
{
  "type": "ERROR",
  "data": {
    "code": "WAITING-015",
    "message": "방장만 게임을 시작할 수 있습니다."
  }
}
```

> `GAME_START` 이벤트 형식은 [WS] 대기방 상태 수신 문서 참조.
> RANDOM 방은 START_GAME이 아니라 양쪽 `READY_STATUS`로 카운트다운이 자동 시작된다.
