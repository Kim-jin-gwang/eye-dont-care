# 비밀번호 변경

URL: /api/v1/users/{userId}/password
method: PUT
도메인: User
진행상황: 시작 전

# **비밀번호 변경**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `PUT` |
| URL | `/api/v1/users/{userId}/password` |
| 구분 | 도전 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 마이페이지/설정 |
| 담당자 |  |
| 도메인 | User |
| 설명 | 현재 비밀번호 검증 후 새 비밀번호로 변경 (로컬 계정 한정, 소셜 전용 계정 제외) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 인증된 회원 **본인**만 요청할 수 있습니다. `{userId}`가 토큰의 사용자와 일치해야 하며, 불일치 시 403.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| userId | Long | NOT NULL | 대상 사용자 ID (Path) |
| currentPassword | String | NOT NULL | 현재 비밀번호 (본인 재확인용) |
| newPassword | String | NOT NULL | 새 비밀번호 (비밀번호 정책 충족) |

### **요청 예시**

---

```json
PUT /api/v1/users/42/password
Authorization: Bearer jwt_token_string
Content-Type: application/json

{
  "currentPassword": "OldPass123!",
  "newPassword": "NewPass456!"
}
```

### **Response Elements**

---

응답 data 없음 (`null`)

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "PASSWORD_UPDATE_SUCCESS",
  "message": "비밀번호 변경이 완료되었습니다.",
  "data": null
}
```

### **400 BAD REQUEST**

```json
HTTP/1.1 400
Content-Type: application/json;

{
  "code": "USER-007",
  "message": "현재 비밀번호가 일치하지 않습니다.",
  "data": null
}
```

> 그 밖의 400: `USER-008`(새 비밀번호가 현재와 동일), `USER-009`(소셜 전용 계정은 변경 불가), `COMMON-001`(비밀번호 정책 위반).

### **401 UNAUTHORIZED**

```json
HTTP/1.1 401
Content-Type: application/json;

{
  "code": "SECURITY-001",
  "message": "인증이 필요합니다.",
  "data": null
}
```

### **403 FORBIDDEN**

```json
HTTP/1.1 403
Content-Type: application/json;

{
  "code": "USER-002",
  "message": "해당 사용자 정보에 접근할 수 없습니다.",
  "data": null
}
```

### **500 INTERNAL SERVER ERROR**

```json

{

  "message": "예상하지 못한 서버 오류가 발생했습니다.",
  "data": null
}
```
