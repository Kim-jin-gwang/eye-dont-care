# 게임별 랭킹 조회

URL: /api/v1/rankings/{gameName}
method: GET
도메인: Ranking
진행상황: 시작 전

# **게임별 랭킹 조회 (전체)**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/rankings/{gameName}` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 랭킹 상세 |
| 담당자 |  |
| 도메인 | Ranking |
| 설명 | 특정 게임의 이번 주 전체 랭킹(페이지네이션) + 내 순위. "전체 랭킹 보기"용 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원. `myRank`는 요청자 기준.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| gameName | String(enum) | NOT NULL | 게임(Path). `HOCKEY`/`EYEFIGHT`/`DRAWING`/`RHYTHM`/`BLINK` |
| page | Integer | NULL | 1부터(기본 1) |
| size | Integer | NULL | 페이지 크기(기본 20) |

### **요청 예시**

---

```json
GET /api/v1/rankings/BLINK?page=1&size=20
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| gameName | String(enum) | 게임 |
| rankType | String(enum) | `WIN_COUNT` / `BEST_SCORE` |
| unit | String(enum) | `win` / `second` / `point` / `count` |
| period | String(enum) | `weekly` |
| weekStart | String(ISO date) | 이번 주 시작(KST 월요일) |
| rankings | Array | {rank, userId, nickname, value, achievedAt} |
| myRank | Object\|null | 내 순위 {rank, value}. 미기록 시 null |
| page / size | Integer | 현재 페이지·크기 |
| totalElements | Long | 전체 인원 |
| totalPages | Integer | 전체 페이지 수 |

> 정렬: 지표 내림차순, 동점은 **먼저 달성한 순**(achievedAt asc). `value`는 게임 점수(눈싸움=초, 정수).

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "GAME_RANKING_FOUND",
  "message": "게임 랭킹을 조회했습니다.",
  "data": {
    "gameName": "BLINK",
    "rankType": "BEST_SCORE",
    "unit": "count",
    "period": "weekly",
    "weekStart": "2026-08-03",
    "rankings": [
      { "rank": 1, "userId": 1, "nickname": "방울반짝", "value": 128, "achievedAt": "2026-08-03T09:12:00Z" },
      { "rank": 2, "userId": 7, "nickname": "졸린너구리", "value": 116, "achievedAt": "2026-08-04T02:30:00Z" }
    ],
    "myRank": { "rank": 7, "value": 88 },
    "page": 1,
    "size": 20,
    "totalElements": 42,
    "totalPages": 3
  },
}
```

### **400 BAD REQUEST**

```json
{ "code": "RANKING-001", "message": "지원하지 않는 게임입니다.", "data": null }
```

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

> 랭킹 지표는 `game_result[slot].score`(에어하키만 `outcome=WIN` 카운트 = `WIN_COUNT`). 눈싸움은 초(정수, `unit=second`).
