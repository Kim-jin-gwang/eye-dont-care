# 내 소모임 조회

URL: /api/v1/groups/me
method: GET
도메인: Group
진행상황: 시작 전

# **내 소모임 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/groups/me` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 커뮤니티/소모임 |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 내가 속한 소모임 목록(OWNER·MEMBER 모두). 가입 상태이므로 joinCode 포함 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원 본인의 소속만 조회.

### **Request Elements**

---

요청 파라미터 없음

### **요청 예시**

---

```json
GET /api/v1/groups/me
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| groups | Array | 내 소모임 카드 목록(필드는 "소모임 생성" 응답과 동일). 모두 `isJoined=true` |

### **응답 예시**

---
