# 소모임 상세 조회

URL: /api/v1/groups/{groupId}
method: GET
도메인: Group
진행상황: 시작 전

# **소모임 상세 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/groups/{groupId}` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 커뮤니티/소모임 |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 소모임 카드 + 멤버 명단(memberList). `joinCode`는 가입자에게만 노출 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원. `joinCode`는 해당 소모임 가입자에게만 응답에 포함된다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| groupId | Long | NOT NULL | 소모임 ID(Path) |

### **요청 예시**

---

```json
GET /api/v1/groups/1
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

"소모임 생성" 응답의 공통 카드 필드 + 아래:

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| memberList | Array | {userId, nickname, role(`OWNER`/`MEMBER`), joinedAt} |

### **응답 예시**

---

Content-Type: application/json;

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

### **404 NOT FOUND**

```json
{ "code": "GROUP-001", "message": "소모임을 찾을 수 없습니다.", "data": null }
```

> 비가입자는 `joinCode`가 null, `isJoined`·`isOwner`는 false로 내려온다.
