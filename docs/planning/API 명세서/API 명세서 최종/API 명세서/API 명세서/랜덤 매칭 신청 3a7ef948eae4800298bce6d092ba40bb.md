# 랜덤 매칭 신청

URL: /api/v1/match/join
method: POST
도메인: Matchmaking
진행상황: 시작 전

# **랜덤 매칭 신청**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `POST` |
| URL | `/api/v1/match/join` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 공통(회원/게스트) |
| 사용할 페이지 | 로비/매칭 |
| 담당자 |  |
| 도메인 | Matchmaking |
| 설명 | gameType 큐 등록(회원 USER:/게스트 GUEST: 키). 중복 신청 불가 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 조건부 | 회원: JWT 액세스 토큰(Bearer) |
| X-Guest-Session-Id | String(UUID) | 조건부 | 게스트: 기존 게스트 세션 ID. 없거나 만료면 서버가 새로 발급 |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 회원 또는 게스트가 요청할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| gameType | String(enum) | NOT NULL | 매칭할 게임 종류 |

### **요청 예시**

---

```json
POST /api/v1/match/join
Authorization: Bearer jwt_token_string
Content-Type: application/json

{
  "gameType": "EYEFIGHT"
}
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| participantKey | String | NOT NULL | `USER:{userId}` 또는 `GUEST:{uuid}` |
| gameType | String(enum) | NOT NULL | 매칭 게임 |
| matchStatus | String(enum) | NOT NULL | `SEARCHING` 또는 `ENTERING_ROOM`(대기자 있어 즉시 성사) |
| waitingRoomId | String(UUID) | NULL | 성사 시 대기방 ID, 아니면 null |
| queuedAt | String(ISO-8601) | NOT NULL | 큐 등록 시각 |
| guestSessionId | String(UUID) | 게스트 한정 | 게스트만 내려감. 재사용/신규 발급된 세션 ID |
| guestNickname | String | 게스트 한정 | 게스트만 내려감. 표시 닉네임 |

### **응답 예시**

---

### **200 OK (게스트)**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "MATCH_QUEUED",
  "message": "랜덤 매칭이 접수되었습니다.",
  "data": {
    "participantKey": "GUEST:019abcde-5678-4abc-8def-0123456789ab",
    "gameType": "EYEFIGHT",
    "matchStatus": "SEARCHING",
    "waitingRoomId": null,
    "queuedAt": "2026-07-30T09:00:00Z",
    "guestSessionId": "019abcde-5678-4abc-8def-0123456789ab",
    "guestNickname": "졸린너구리"
  },
}
```

> 회원 응답은 `guestSessionId`·`guestNickname`이 포함되지 않는다.

### **400 BAD REQUEST**

```json
HTTP/1.1 400
Content-Type: application/json;

{
  "code": "MATCHMAKING-002",
  "message": "지원하지 않는 게임입니다.",
  "data": null,
}
```

### **401 UNAUTHORIZED**

```json
HTTP/1.1 401
Content-Type: application/json;

{
  "code": "SECURITY-002",
  "message": "유효하지 않은 액세스 토큰입니다.",
  "data": null,
}
```

### **409 CONFLICT**

```json
HTTP/1.1 409
Content-Type: application/json;

{
  "code": "MATCHMAKING-001",
  "message": "이미 매칭 대기 중입니다.",
  "data": null,
}
```

### **500 INTERNAL SERVER ERROR**

```json
HTTP/1.1 500
Content-Type: application/json;

{
  "code": "UNEXPECTED_SERVER_ERROR",
  "message": "예상하지 못한 서버 오류가 발생했습니다.",
  "data": null,
}
```
