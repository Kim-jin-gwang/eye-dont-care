# 소모임 후기 목록 조회

URL: /api/v1/groups/{groupId}/posts
method: GET
도메인: Group
진행상황: 완료

# **소모임 후기 목록 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 완료 |
| Method | `GET` |
| URL | `/api/v1/groups/{groupId}/posts` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 커뮤니티/소모임 상세(후기 게시판) |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 소모임 후기 글 목록(최신순)을 댓글과 함께 조회. 가입 여부와 무관하게 회원이면 열람 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |

### **Role Requirement**

---

**권한:** 인증된 회원. 조회는 가입 여부와 무관하다(작성은 가입자만 가능).

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| groupId | Long | NOT NULL | 소모임 ID(Path) |

### **요청 예시**

---

```json
GET /api/v1/groups/1/posts
Authorization: Bearer jwt_token_string
```

### **Response Elements**

---

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| posts | Array | 후기 글 목록(최신순) |
| posts[].postId | Long | 후기 글 ID |
| posts[].author | String | 작성자 닉네임 |
| posts[].isLeader | Boolean | 작성자가 소모임 방장이면 true |
| posts[].content | String | 후기 내용(최대 500자) |
| posts[].createdAt | String(ISO8601) | 작성 시각 |
| posts[].comments | Array | 댓글 목록(오래된 순) |
| posts[].comments[].commentId | Long | 댓글 ID |
| posts[].comments[].author | String | 댓글 작성자 닉네임 |
| posts[].comments[].content | String | 댓글 내용(최대 200자) |
| posts[].comments[].createdAt | String(ISO8601) | 작성 시각 |

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "GROUP_POST_LIST_FOUND",
  "message": "후기 목록을 조회했습니다.",
  "data": {
    "posts": [
      {
        "postId": 1,
        "author": "졸린너구리",
        "isLeader": true,
        "content": "오늘도 눈 운동 완료!",

        "comments": [
          {
            "commentId": 1,
            "author": "멤버A",
            "content": "저도 같이해요",
            "createdAt": "2026-08-05T09:34:00Z"
          }

  },
}
```

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

### **404 NOT FOUND**

```json
{ "code": "GROUP-001", "message": "소모임을 찾을 수 없습니다.", "data": null }
```

> 후기가 없으면 `posts`는 빈 배열로 내려온다.
