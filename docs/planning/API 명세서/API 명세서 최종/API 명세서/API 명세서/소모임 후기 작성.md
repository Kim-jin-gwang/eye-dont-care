# 소모임 후기 작성

URL: /api/v1/groups/{groupId}/posts
method: POST
도메인: Group
진행상황: 완료

# **소모임 후기 작성**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 완료 |
| Method | `POST` |
| URL | `/api/v1/groups/{groupId}/posts` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원(가입자) |
| 사용할 페이지 | 커뮤니티/소모임 상세(후기 게시판) |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 소모임 후기 글 작성. 해당 소모임 가입자만 가능 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 해당 소모임 **가입자만** 작성할 수 있다. 비가입자는 `GROUP-005`(403).

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| groupId | Long | NOT NULL | 소모임 ID(Path) |
| content | String | NOT NULL | 후기 내용(1~500자) |

### **요청 예시**

---

```json
POST /api/v1/groups/1/posts
Authorization: Bearer jwt_token_string
Content-Type: application/json

{ "content": "오늘도 눈 운동 완료!" }
```

### **Response Elements**

---

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| postId | Long | 생성된 후기 글 ID |
| author | String | 작성자 닉네임 |
| isLeader | Boolean | 작성자가 소모임 방장이면 true |
| content | String | 후기 내용 |
| createdAt | String(ISO8601) | 작성 시각 |
| comments | Array | 새 글이므로 빈 배열 |

### **응답 예시**

---

### **201 CREATED**

```json
HTTP/1.1 201
Content-Type: application/json;

{
  "code": "GROUP_POST_CREATE_SUCCESS",
  "message": "후기를 작성했습니다.",
  "data": {
    "postId": 1,
    "author": "졸린너구리",
    "isLeader": true,
    "content": "오늘도 눈 운동 완료!",
    "createdAt": "2026-08-05T09:33:22Z",
    "comments": []
  },
}
```

### **400 BAD REQUEST**

```json
{ "code": "COMMON-001", "message": "요청 값이 올바르지 않습니다.", "data": { "fieldErrors": [ { "field": "content", "reason": "후기는 500자 이하여야 합니다." } ] } }
```

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

### **403 FORBIDDEN**

```json
{ "code": "GROUP-005", "message": "소모임 멤버가 아닙니다.", "data": null }
```

### **404 NOT FOUND**

```json
{ "code": "GROUP-001", "message": "소모임을 찾을 수 없습니다.", "data": null }
```

> 최대 글자 수(500)는 프론트 입력 제한과 동일하게 서버에서도 검증한다.
