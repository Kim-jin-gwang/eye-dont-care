# **게임 상세 조회**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `GET` |
| URL | `/api/v1/games/{gameId}` |
| 구분 | 필수 |
| 인증 | 불필요 |
| 역할 | 공통 |
| 사용할 페이지 | 게임 상세 |
| 담당자 |  |
| 도메인 | Game |
| 설명 | 규칙·눈 조작·지원 모드/난이도·인원 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| - | - | - | 인증/본문 없음 |

### **Role Requirement**

---

**권한:** 누구나 조회할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| gameId | Long | NOT NULL | 게임 ID(Path) |

### **요청 예시**

---

```json
GET /api/v1/games/{gameId}
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| gameId | Long | NOT NULL | 게임 ID |
| gameName | String(enum) | NOT NULL | 게임 종류 |
| playMode | String(enum) | NOT NULL | `SOLO`/`INVITE`/`RANDOM`/`AI` |
| difficulty | int | NULL | 난이도(있는 조합만, 예: EYEFIGHT AI 1/2/3), 없으면 null |

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "GAME_FOUND",
  "message": "게임 상세를 조회했습니다.",
  "data": {
    "gameId": 1,
    "gameName": "EYEFIGHT",
    "playMode": "SOLO",
    "difficulty": null
  },
}
```

> `rule`·`controlGuide`·`playModes`·`difficulties`·`minPlayers`·`maxPlayers`는 현재 응답에 없다(미구현). 상세는 게임 카탈로그 한 행({gameId, gameName, playMode, difficulty})을 그대로 돌려준다.

### **404 NOT FOUND**

```json
HTTP/1.1 404
Content-Type: application/json;

{
  "code": "GAME-001",
  "message": "게임을 찾을 수 없습니다.",
  "data": null,
}
```

### **500 INTERNAL SERVER ERROR**

```json
HTTP/1.1 500
Content-Type: application/json;

{
  "code": "UNEXPECTED_SERVER_ERROR",
  "message": "예상하지 못한 서버 오류가 발생했습니다.",
  "data": null,
}
```
