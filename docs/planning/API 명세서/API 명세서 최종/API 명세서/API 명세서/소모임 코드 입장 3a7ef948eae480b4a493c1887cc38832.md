도메인: Group
진행상황: 시작 전

# **소모임 코드 입장**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `POST` |
| URL | `/api/v1/groups/join` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 커뮤니티/소모임 |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 6자리 코드로 소모임 가입(PUBLIC·PRIVATE 공통) |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 인증된 회원만 가입할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| groupCode | String(CHAR6) | NOT NULL | 입장 코드 |

### **요청 예시**

---

```json
POST /api/v1/groups/join
Authorization: Bearer jwt_token_string
Content-Type: application/json

{ "groupCode": "A1B2C3" }
```

### **Response Elements**

---

"소모임 생성"과 동일한 카드 응답. 요청자는 방금 가입했으므로 `isJoined=true`, `isOwner=false`, `joinCode` 포함.

### **응답 예시**

---

### **200 OK**

```json
HTTP/1.1 200
Content-Type: application/json;

{
  "code": "GROUP_JOIN_SUCCESS",
  "message": "소모임에 가입했습니다.",
  "data": {
    "groupId": 1,
    "name": "눈운동 모임",
    "description": "매일 저녁 같이 게임해요",
    "members": 3,
    "capacity": 10,
    "visibility": "PUBLIC",
    "leader": "졸린너구리",
    "isOwner": false,
    "isJoined": true,
    "joinCode": "A1B2C3",
    "createdAt": "2026-08-03T00:00:00Z"
  },
}
```

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

### **404 NOT FOUND**

```json
{ "code": "GROUP-002", "message": "유효하지 않은 소모임 코드입니다.", "data": null }
```

### **409 CONFLICT**

```json
{ "code": "GROUP-003", "message": "소모임 정원이 가득 찼습니다.", "data": null }
```

> 이미 가입한 소모임이면 `GROUP-004`(409, "이미 가입한 소모임입니다.").
