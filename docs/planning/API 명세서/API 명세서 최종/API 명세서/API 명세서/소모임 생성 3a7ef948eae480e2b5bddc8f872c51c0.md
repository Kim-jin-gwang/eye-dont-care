# 소모임 생성

URL: /api/v1/groups
method: POST
도메인: Group
진행상황: 시작 전

# **소모임 생성**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `POST` |
| URL | `/api/v1/groups` |
| 구분 | 필수 |
| 인증 | 필요 |
| 역할 | 회원 |
| 사용할 페이지 | 커뮤니티/소모임 |
| 담당자 |  |
| 도메인 | Group |
| 설명 | 소모임 생성(생성자 자동 OWNER 가입 + 6자리 코드 발급). 응답은 프론트 CommunityGroup 모양 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Authorization | String | 필수 | JWT 액세스 토큰(Bearer) |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 인증된 회원만 생성할 수 있습니다. (게스트 불가)

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| name | String | NOT NULL | 소모임 이름(≤50) |
| description | String | NULL | 소개(≤255) |
| visibility | String(enum) | NOT NULL | `PUBLIC`(목록 노출) / `PRIVATE`(코드로만) |
| capacity | Integer | NULL | 정원(2~100, **기본 50**) |

### **요청 예시**

---

```json
POST /api/v1/groups
Authorization: Bearer jwt_token_string
Content-Type: application/json

{
  "name": "눈운동 모임",
  "description": "매일 저녁 같이 게임해요",
  "visibility": "PUBLIC",
  "capacity": 30
}
```

### **Response Elements** (공통 소모임 카드)

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| groupId | Long | NOT NULL | 소모임 ID |
| name | String | NOT NULL | 이름 |
| description | String | NULL | 소개 |
| members | Integer | NOT NULL | 현재 인원(생성 직후 1) |
| capacity | Integer | NOT NULL | 정원 |
| visibility | String(enum) | NOT NULL | `PUBLIC` / `PRIVATE` |
| leader | String | NOT NULL | 방장 닉네임 |
| isOwner | Boolean | NOT NULL | 요청자가 방장인지 |
| isJoined | Boolean | NOT NULL | 요청자가 가입 상태인지 |
| joinCode | String(CHAR6) | 가입자 한정 | 입장 코드. 비가입자는 null |
| createdAt | String(ISO-8601) | NOT NULL | 생성 시각 |

### **응답 예시**

---

### **201 CREATED**

```json
HTTP/1.1 201
Content-Type: application/json;

{
  "code": "GROUP_CREATE_SUCCESS",
  "message": "소모임을 생성했습니다.",
  "data": {
    "groupId": 1,
    "name": "눈운동 모임",
    "description": "매일 저녁 같이 게임해요",
    "members": 1,
    "capacity": 30,
    "visibility": "PUBLIC",
    "leader": "졸린너구리",
    "isOwner": true,
    "isJoined": true,
    "joinCode": "A1B2C3",
    "createdAt": "2026-08-03T00:00:00Z"
  },
}
```

### **400 BAD REQUEST**

```json
{
  "code": "COMMON-001",
  "message": "요청 값이 올바르지 않습니다.",
  "data": { "fieldErrors": [ { "field": "name", "reason": "소모임 이름은 필수입니다." } ] }
}
```

### **401 UNAUTHORIZED**

```json
{ "code": "SECURITY-001", "message": "인증이 필요합니다.", "data": null }
```

### **503 SERVICE UNAVAILABLE**

```json
{ "code": "GROUP-009", "message": "소모임 코드를 생성할 수 없습니다.", "data": null }
```

> visibility는 대문자(`PUBLIC`/`PRIVATE`)로 주고받는다(프론트에서 표기 변환). 입장 코드는 서버가 자동 발급한다.
