# 회원가입

URL: /api/v1/auth/signup
method: POST
도메인: Auth
진행상황: 시작 전

# **이메일 회원가입**

| 항목 | 내용 |
| --- | --- |
| 진행상황 | 시작 전 |
| Method | `POST` |
| URL | `/api/v1/auth/signup` |
| 구분 | 도전 |
| 인증 | 불필요 |
| 역할 | 비회원 |
| 사용할 페이지 | 회원가입 페이지 |
| 담당자 |  |
| 도메인 | Auth |
| 설명 | 이메일·비밀번호로 가입. 닉네임은 서버가 자동 생성하고, 가입 즉시 토큰을 발급한다 |

### **Request Header**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Content-Type | String | 필수 | application/json |

### **Role Requirement**

---

**권한:** 비회원(누구나) 요청할 수 있습니다.

### **Request Elements**

---

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| email | String | NOT NULL | 이메일 |
| password | String | NOT NULL | 비밀번호 |

> 닉네임은 요청으로 받지 않는다. 서버가 랜덤 닉네임을 생성해 부여한다.

### **요청 예시**

---

```json
POST /api/v1/auth/signup
Content-Type: application/json

{
  "email": "user@example.com",
  "password": "Password123!"
}
```

### **Response Elements**

---

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| accessToken | String | NOT NULL | 액세스 토큰 |
| refreshToken | String | NOT NULL | 리프레시 토큰 |

### **응답 예시**

---

### **201 CREATED**

```json
HTTP/1.1 201
Content-Type: application/json;

{
  "code": "AUTH_SIGNUP_SUCCESS",
  "message": "회원가입이 완료되었습니다.",
  "data": {
    "accessToken": "eyJ...",
    "refreshToken": "eyJ..."
  },
}
```

### **400 BAD REQUEST**

```json
HTTP/1.1 400
Content-Type: application/json;

{
  "code": "COMMON-001",
  "message": "요청 값이 올바르지 않습니다.",
  "data": {
    "fieldErrors": [
      { "field": "email", "reason": "이메일 형식이 올바르지 않습니다." }
    ]
  },
}
```

### **409 CONFLICT**

```json
HTTP/1.1 409
Content-Type: application/json;

{
  "code": "AUTH-001",
  "message": "이미 사용 중인 이메일입니다.",
  "data": null,
}
```

### **500 INTERNAL SERVER ERROR**

```json
HTTP/1.1 500
Content-Type: application/json;

{
  "code": "UNEXPECTED_SERVER_ERROR",
  "message": "예상하지 못한 서버 오류가 발생했습니다.",
  "data": null,
}
```
