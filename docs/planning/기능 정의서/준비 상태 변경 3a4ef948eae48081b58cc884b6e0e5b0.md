# 준비 상태 변경

구분: 필수
도메인: WaitingRoom
액터: 공통
한 줄 설명: 사용자는 준비 상태를 변경할 수 있다.

- WebSocket 연결 `C → S`
- PLAYER는 준비 완료 버튼 클릭 시 전달한다.
- 초대방 HOST는 캘리브레이션 완료 시 자동으로 준비 완료 상태를 전달하며 별도의 준비 버튼을 표시하지 않는다.
- 입장 시 `is_ready=false`이고 준비 완료 시 `true`로 변경한다.
- 준비 완료 전에 카메라와 얼굴·눈 인식 여부를 확인하지만 해당 상태는 Redis에 저장하지 않는다.

#### PLAYER

<aside>

캘리브레이션 완료
→ 준비 완료 버튼 활성화
→ 버튼 클릭
→ is_ready = true 전송

</aside>

#### HOST

<aside>

캘리브레이션 완료
→ 별도 준비 버튼 없이
→ 기존 준비 상태 변경 메시지로 is_ready = true 자동 전송
→ 모든 참가자 is_ready = true이면 게임 시작 버튼 활성화

</aside>
