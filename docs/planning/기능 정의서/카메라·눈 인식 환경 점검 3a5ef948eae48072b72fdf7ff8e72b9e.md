# 카메라·눈 인식 환경 점검

도메인: Calibration
처리 내용: 사용자가 대기방에서 카메라 권한과 얼굴·눈 인식 가능 여부를 확인한다.
트리거: 사용자 대기방 입장

- 점검 전 카메라 사용 안내를 표시한다.
- 권한 거부·카메라 미연결·인식 실패 시 원인을 안내하고 재시도를 제공한다.

#### 사용자 흐름

<aside>

① 사용자가 대기방에 입장한다.

② 클라이언트가 카메라 설정 안내를 표시한다.
예: “게임을 시작하려면 카메라 설정이 필요합니다.”, “얼굴이 화면 중앙에 보이도록 자세를 조정하고 카메라 사용을 허용해 주세요.”

③ 사용자가 안내를 확인하면 카메라 권한과 동작 상태를 점검한다.

④ 얼굴과 눈이 정상적으로 인식되면 캘리브레이션을 시작한다.

⑤ 클라이언트가 필요한 눈 동작을 측정하고
캘리브레이션 완료 조건을 자동으로 판단한다.

⑥ 캘리브레이션이 완료되면 `준비 완료` 버튼을 활성화한다.

⑦ 사용자가 `준비 완료` 버튼을 누르면
서버에 대기방 READY 상태를 전달한다.

⑧ 모든 참가자가 READY가 되면

- 랜덤방: 자동으로 게임 시작
- 초대방: 방장의 게임 시작 버튼 활성화

⑨ 게임 시작이 확정0되면 카운트다운 후 게임을 시작한다.

</aside>

#### 화면 상태 예시

<aside>

카메라 설정 안내
→ 카메라 권한 확인
→ 얼굴·눈 인식 확인
→ 캘리브레이션 진행 중
→ 캘리브레이션 완료
→ 준비 완료 가능

</aside>
