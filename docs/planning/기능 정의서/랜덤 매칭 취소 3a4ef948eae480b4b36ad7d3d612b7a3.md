# 랜덤 매칭 취소

구분: 필수
도메인: Matchmaking
액터: 공통
한 줄 설명: 사용자는 진행 중인 랜덤 매칭을 취소할 수 있다.

- `SEARCHING` 상태에서만 취소할 수 있다.
- 취소 시 참가자를 게임별 매칭 큐와 매칭 참가자 상태에서 제거한다.
- 매칭이 성사되어 `ENTERING_ROOM`으로 전환된 후에는 취소할 수 없다.

1. 사용자가 앱 내부의 뒤로 가기·닫기 버튼으로 이탈
→ `랜덤 매칭 취소` API 호출
2. 새로고침·브라우저 종료·네트워크 끊김
→ 서버가 WebSocket 연결 종료나 TTL로 자동 정리
