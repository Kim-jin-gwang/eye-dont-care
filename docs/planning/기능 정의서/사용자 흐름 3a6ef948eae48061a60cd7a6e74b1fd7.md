# 사용자 흐름

도메인: Matchmaking

#### 사용자 흐름

<aside>

① 사용자가 랜덤 매칭을 신청한다.

② 서버가 사용자를 매칭 대기열에 등록한다.

③ 프론트는 매칭 대기 화면을 표시하고
결과 수신을 위한 WebSocket 연결을 유지한다.

④ 매칭 진행 중 사용자는
현재 상태를 조회하거나 매칭을 취소할 수 있다.

⑤ 서버가 조건에 맞는 상대를 찾는다.

⑥ 서버 내부에서 랜덤 대기방과 참가자 정보를 생성한다.

⑦ 대기방 생성 성공 후
양쪽 사용자에게 매칭 성공 결과를 전달한다.

⑧ 사용자는 생성된 대기방으로 이동한다.

⑨ 제한 시간 내 상대를 찾지 못하거나 오류가 발생하면
해당 종료 결과를 전달하고 대기 상태를 정리한다.

</aside>

상태 흐름

├─ 제한 시간 경과 → 시간 초과
└─ 내부 오류 → 실패
