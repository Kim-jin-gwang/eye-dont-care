# 게임 결과 제출

도메인: GameResult
액터: 공통
한 줄 설명: 사용자는 게임 종료 후 계산된 최종 결과를 서버에 저장할 수 있다.

- 서버는 요청자의 참가 여부, 게임과 플레이 모드의 유효성, 결과 형식, 참가자별 결과 정합성 및 중복 제출 여부를 검증한다.
- 게임별 상세 결과는 `game_result`로 전달하며 게임·모드별 필수 필드와 검증 규칙은 API 명세에서 정의한다.
- 정상 종료와 명확한 몰수 결과만 파이프라인으로 전달한다.

게임마다 종료 조건이 다르나, 최종 결과가 확정되는 순간에 해당 API를 호출.

#### 게임 나가기 / 비정상 종료 구분

- 사용자가 게임 중 `나가기` 버튼을 누르면 해당 시점까지의 결과가 자동 제출됨
    
    <aside>
    
    게임 포기 버튼 클릭
    → 포기 확인
    → FORFEIT 결과 생성
    → 결과 제출 API 자동 호출
    
    </aside>
    
- 새로고침·탭 종료·네트워크 단절 — 등의 비정상 종료 시 결과는 저장하지 않음
    
    <aside>
    
    브라우저 강제 종료
    → 클라이언트 실행 중단
    → 결과 계산·제출 불가능할 수 있음
    
    </aside>
    

#### 공통 필드 / 게임별 필드

```jsx
{
  "play_id": "019abcde-1234",
  "game_id": 1,
  "play_mode": "MULTI",
  "participants": [
    {
      "participant_id": "user-1",
      "outcome": "WIN",
      "rank": 1,
      "score": 5
    },
    {
      "participant_id": "user-2",
      "outcome": "LOSE",
      "rank": 2,
      "score": 3
    }
  ],
  "game_result": {
    "duration_ms": 15200,
    "total_rounds": 8
  }
}
```
